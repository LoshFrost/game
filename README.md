# \U0001F3AE Малый-Большой-Равный

Telegram Mini App \u2014 игра по принципу \u00abкамень-ножницы-бумага\u00bb на 9 числах.

## \u2696\ufe0f Правила (идеальный баланс)

У каждого числа \u2014 **ровно 4 победы и 4 поражения**. Никаких перекачанных или слабых чисел.

### Три группы

- **Малые**: 1, 2, 3
- **Равные**: 4, 5, 6
- **Большие**: 7, 8, 9

### Между группами (камень-ножницы-бумага)

- Малые бьют Равных
- Равные бьют Больших
- Большие бьют Малых

### Внутри группы (цикл)

- 1 бьет 2, 2 бьет 3, 3 бьет 1
- 4 бьет 5, 5 бьет 6, 6 бьет 4
- 7 бьет 8, 8 бьет 9, 9 бьет 7

### Одинаковые числа \u2014 ничья

### Пример

| Ты | Соперник | Кто победил | Почему |
|----|----------|-------------|--------|
| 2 | 5 | Ты | Малое бьет Равное |
| 5 | 8 | Ты | Равное бьет Большое |
| 8 | 2 | Ты | Большое бьет Малое |
| 1 | 2 | Ты | Внутри малых: 1 бьет 2 |
| 5 | 5 | Ничья | Одинаковые числа |

## Режимы

1. Играть с ботом \u2014 бот выбирает число случайно, анимации, история раундов
2. Играть вдвоем \u2014 передаете телефон по очереди
3. Играть онлайн \u2014 поиск соперника через WebSocket (требует сервер)

## Структура проекта

- index.html \u2014 веб-интерфейс (фронтенд + логика игры)
- server.js \u2014 WebSocket сервер для онлайн-режима (Node.js)
- package.json \u2014 зависимости для server.js
- bot.py \u2014 Telegram-бот: команда /find_opponent для поиска соперника
- README.md \u2014 этот файл

## Запуск

### Фронтенд (GitHub Pages)

1. Загрузи index.html в репозиторий на GitHub
2. Включи GitHub Pages: Settings -> Pages -> Branch: main -> Save
3. Получи ссылку вида https://username.github.io/repo-name/
4. В @BotFather: создай Web App и укажи эту ссылку

### Бот-координатор (PythonAnywhere)

1. Загрузи bot.py на PythonAnywhere
2. Установи: pip install aiogram
3. Вставь токен бота в bot.py
4. Запусти: python3 bot.py
5. В группе: /find_opponent \u2014 бот пришлет ссылку на игру

### Сервер онлайн (локально через ngrok)

1. Скачай server.js и package.json на компьютер
2. Установи: npm install
3. Запусти: node server.js (порт 3000)
4. Проброси: ngrok http 3000
5. Вставь ссылку от ngrok в index.html (функция startOnlineGame)

## Команды бота

- /find_opponent \u2014 создать комнату и получить ссылку для игры онлайн
- /start \u2014 главное меню
- /rules \u2014 правила
