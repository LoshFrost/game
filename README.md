# 🎮 Малый-Большой-Равный

Telegram бот + Web App с тремя режимами игры.

## 📁 Структура

```
├── server.js          — бот + WebSocket сервер
├── public/
│   └── index.html     — веб-интерфейс
├── package.json
└── .env.example
```

## 🚀 Запуск

### Локально

```bash
npm install
BOT_TOKEN=твой_токен PORT=3000 node server.js
```

Открой http://localhost:3000 — увидишь веб-интерфейс.

### Деплой на Render.com (бесплатно, с HTTPS)

1. Создай репозиторий на GitHub с этими файлами
2. Зайди на render.com → New → Web Service
3. Подключи репозиторий
4. Настройки:
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Environment Variables:
     - BOT_TOKEN = твой_токен
     - WEBAPP_URL = https://твой-адрес.onrender.com
5. Deploy
6. Получи HTTPS-ссылку

### Подключение к Telegram

1. В @BotFather:
   - /newbot → создай бота
   - /setdomain → укажи свой HTTPS-адрес
2. Бот готов!

## 🎯 Три режима

1. **🤖 Играть с ботом** — Web App, анимации, история раундов
2. **👥 Играть вдвоём** — передаёте телефон по очереди
3. **🌐 Играть онлайн** — ищет соперника через WebSocket

## 📋 Команды бота

- `/start` — главное меню
- `/game` — начать игру (в группе: два игрока пишут числа 1-9)
- `/rules` — правила
- `/web` — открыть веб-версию

## ⚖️ Правила

Числа 1-9. У каждого 4 победы и 4 поражения.
- Малое бьёт большое
- Большое чёт бьёт малое нечёт
- Малое чёт бьёт большое нечёт
- 6 бьёт 9 (исключение)
